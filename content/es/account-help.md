## Registro con datos correctos

Antes de registrarte, confirma que cumples la edad legal y que el servicio está permitido donde resides. Los datos deben coincidir con tus documentos, porque las diferencias pueden retrasar la verificación o una retirada.

| Paso | Qué comprobar | Error habitual |

| Elegibilidad | Edad y disponibilidad regional | Registro donde hay restricciones |
| Datos personales | Nombre, fecha de nacimiento y dirección | Diferencias con el documento |
| Credenciales | Contraseña única y correo accesible | Reutilizar una contraseña |

No abras cuentas adicionales para eludir restricciones. Si falla una comprobación, sigue el proceso oficial de recuperación o soporte.

## Información de acceso

## Información de acceso

Abre la web oficial del operador y comprueba el dominio antes de introducir credenciales. Si no puedes entrar, utiliza el proceso oficial de recuperación de contraseña.

### Seguridad de la cuenta

No compartas contraseñas, códigos de un solo uso ni enlaces de recuperación. Desconfía de anuncios y mensajes que dirijan a páginas de inicio de sesión desconocidas.

### Si falla el acceso

Comprueba posibles errores de escritura y avisos del servicio. Para problemas específicos, utiliza el soporte indicado en la web verificada del operador.

## Inicio de sesión y recuperación del acceso

Si no puedes iniciar sesión, comprueba primero el correo, el idioma del teclado y el mensaje que aparece. Utiliza únicamente el proceso oficial para restablecer la contraseña. No compartas códigos de un solo uso ni la contraseña con personas que afirmen ser soporte.

| Síntoma | Primera comprobación | Siguiente paso seguro |
|---|---|---|
| Contraseña rechazada | Teclado y correo | Restablecimiento oficial |
| Falta el correo | Spam y dirección | Solicitar otra confirmación |
| La página no carga | Navegador, red y extensiones | Recargar o probar otro navegador |
| Cuenta restringida | Aviso de la cuenta | Contactar con soporte oficial |

Usa una contraseña única y protege tu correo, ya que suele utilizarse para recuperar el acceso.

## Lista de comprobación de acceso

El enlace de recuperación es sensible. No lo reenvíes, no compartas códigos de un solo uso ni subas documentos de identidad a un sitio editorial. Si el problema continúa, guarda el mensaje de error y contacta con el operador mediante los datos publicados en su web oficial.
