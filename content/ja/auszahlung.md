出金には、申請、運営者による確認、必要に応じた本人確認、決済サービスや銀行による処理など、複数の段階があります。それぞれの段階で所要時間が異なる場合があります。

このガイドは一般的な情報を提供するもので、特定の運営者の出金時間や条件を保証するものではありません。Instant Casinoは情報サイトであり、プレイヤーの残高を預かったり、決済を処理したりするものではありません。

## 出金申請の前に確認すること

- 本人確認は完了していますか。追加書類の提出依頼はありませんか。
- 選択した出金方法は、利用国とアカウントで利用できますか。
- 必要な場合、アカウントと決済手段の名義は一致していますか。
- 有効なボーナスや未完了の賭け条件はありませんか。
- 最低額・最高額、手数料、通貨換算費用はありますか。
- 運営者の審査時間と銀行・決済事業者の送金時間は区別されていますか。

一般的な比較表や古い口コミよりも、ログイン後の決済画面とアカウントに適用される最新の規約を優先してください。

## 出金の主な流れ

### 1. 出金申請
決済画面に表示されている方法を選び、金額を入力して確認画面を読みます。確定する前に、通貨、受取人情報、手数料を確認してください。

### 2. 運営者による審査
運営者は、アカウント情報、決済手段の名義、ボーナスの状態、未完了の要件などを確認する場合があります。「保留中」「審査中」という表示は、この段階が完了していないことを示す場合があります。ステータスの意味は運営者によって異なります。

### 3. 本人確認または決済手段の確認
本人確認、年齢、決済手段を利用する権限を確認するため、書類の提出を求められることがあります。必要書類や時期は状況と適用ルールによって異なります。書類は公式の安全なアカウント画面からのみ提出してください。パスワード、ワンタイムコード、カード番号全体を個人宛てに送らないでください。

### 4. 決済事業者または銀行での処理
承認後も、電子ウォレット、カードネットワーク、銀行で処理が続く場合があります。週末、祝日、銀行の営業時間、追加確認などが着金に影響することがあります。支払いがすでに送金されたのか、まだ審査中なのかを確認しましょう。

## 出金が遅れる一般的な理由

| 考えられる理由 | 確認すること |
|---|---|
| 本人確認が未完了 | アカウントに具体的な書類提出依頼があるか。 |
| 登録情報の不一致 | 名義や決済情報が要件と一致しているか。 |
| 内部審査 | 公式通知と取引ステータスを確認する。 |
| ボーナス条件が未完了 | 賭け条件、期限、出金条項を確認する。 |
| 銀行・決済事業者の処理 | 運営者が送金を完了したか確認する。 |
| 金額や通貨の制限 | 申請額、通貨、適用される上限を確認する。 |

遅延だけで不正があったとは判断できません。公式サポートに現在の処理段階と取引参照番号を問い合わせてください。

## 決済方法と出金ルール

入金時に利用できる方法が、出金にも利用できるとは限りません。運営者によっては、元の決済方法への返金を求めたり、追加確認を行ったりします。

| 方法 | 確認すること |
|---|---|
| 銀行カード | カード発行会社がカードへの返金・入金に対応しているか。 |
| 電子ウォレット | 本人確認済みで、出金に有効化されているか。 |
| 銀行振込 | 名義、口座番号、通貨、銀行手数料。 |
| プリペイド | 出金に対応しているか、別の方法が必要か。 |
| 暗号資産 | 通貨、ネットワーク、アドレスの一致、ネットワーク手数料と価格変動リスク。 |

依頼していないメッセージで送られてきた決済アドレスは使用しないでください。暗号資産の送金は取り消せない場合があります。

## ボーナスと未完了の賭け条件

有効なボーナスは出金に影響することがあります。キャンペーン規約によっては、出金申請でボーナスや未完了の進捗が取り消される場合があります。対象ゲーム、期限、最大ベット、出金額にも制限が設けられることがあります。

申請前に、ボーナスが有効か、賭け条件を達成したか、途中出金について規約に何と書かれているかを確認してください。すべてのキャンペーンに共通するルールはありません。[ボーナス条件のガイド]({{< relref "bonuses" >}})もご覧ください。

## 出金が遅れている場合の対応

1. 取引履歴から日付、金額、方法、ステータスを記録します。
2. アカウントの公式通知とメールに書類提出依頼がないか確認します。
3. 経過時間を現在の利用条件と照らし合わせます。
4. 自分で公式サイトまたはアプリを開き、そのサポート窓口に連絡します。
5. まだ審査中なのか、決済事業者に送金済みなのかを確認し、取引参照番号を求めます。

出金の解除、税金、本人確認を名目に、個人や不明なウォレットへ手数料を送らないでください。既存の資金を解放すると言われても、追加で入金しないでください。パスワードやワンタイムコードは決して共有しないでください。

## 居住地域の許可を確認する

ギャンブルに関する規制は国によって異なります。登録や入金の前に、居住地域の規制当局が公開する公式登録簿やリストで、正確なドメイン名とゲームの種類を確認してください。海外のライセンスや決済ロゴだけでは、居住地域での営業許可を証明できません。
