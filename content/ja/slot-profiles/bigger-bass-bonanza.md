**Bigger Bass Bonanza**は、Pragmatic Playが提供する釣りをテーマにしたスロットです。フリースピン中にWildシンボルが画面上のマネーシンボルの値を集めます。Scatterによるボーナス開始、Fisherman Wildによる回収、段階的に上がる倍率の組み合わせが中心となる仕組みです。

## ゲーム構成と確認できる情報

| 項目 | 公式製品ページの情報 |
|---|---|
| 提供元 | Pragmatic Play |
| 盤面 | 4×5形式 |
| Scatterの発動条件 | Scatterが3、4、または5個 |
| フリースピン | Scatter数に応じて10回、15回、20回 |
| Money Symbols | ボーナス中にベット額の最大4,000倍の値が出現 |
| Fisherman Wild | 画面上のMoney Symbolsの値をすべて回収 |
| Wildによる再発動 | 4個目のWildごとに追加フリースピン10回 |
| 倍率の段階 | 2倍、次に3倍、最後に10倍 |
| RTP・ボラティリティ・ベット上限 | 参照した製品ページには記載なし |

4,000倍という数値は、ボーナス中に出現するMoney Symbolsの値についての説明です。ゲーム全体の最大配当を意味するものではありません。RTP、ボラティリティ、ベット上限は、実際に起動したカジノ版のヘルプで確認してください。引用した公式製品ページにはこれらの設定値は記載されていません。

## フリースピンの開始条件

Scatterシンボルがボーナス機能を開始します。Pragmatic Playは、3種類の発動パターンと、それぞれに付与されるフリースピン数を説明しています。

| リール上のScatter数 | フリースピン |
|---:|---:|
| 3 | 10回 |
| 4 | 15回 |
| 5 | 20回 |

そのため、ボーナスの発動条件は機能が始まるかどうかだけでなく、最初に何回のフリースピンが付与されるかにも関係します。実際のベットと配当の規則は、起動中のバージョンのヘルプで確認してください。

## Fisherman WildとMoney Symbols

ボーナス中には、それぞれの値を持つMoney Symbolsが出現することがあります。Wildシンボルには回収機能があり、Fisherman Wildが画面上に見えているMoney Symbolsの値をすべて集めます。

次の2つを分けて理解すると仕組みが明確になります。

1. **Money Symbolsは値を表示する：** その値が回収機能で計算対象になります。
2. **Wildが表示中の値を回収する：** 回収を行うのはWildです。Money Symbolが画面に見えているだけで、値が自動的に払い出されるわけではありません。

Pragmatic Playによると、ボーナス中のMoney Symbolsにはベット額の最大4,000倍の値が付くことがあります。個々のシンボルの値やラウンドの結果を事前に予測することはできません。

## 追加フリースピンと倍率

回収機能には段階的な進行もあります。提供元の説明では、Wildが4個集まるごとに機能が再発動し、追加のフリースピン10回が付与されるとともに、回収した値に適用される倍率が次の段階へ進みます。

提供元が示す倍率の順序は次のとおりです。

- 1回目の再発動：2倍
- 2回目の再発動：3倍
- 最終段階：10倍

そのため、ボーナス中に集めたWildの数が重要になります。ただし、Wildが追加で出現しても特定の金額が保証されるわけではありません。結果は画面上のMoney Symbolsと、起動中のバージョンにおける回収の精算方法によって変わります。

## ボーナス機能から分からないこと

フリースピンの開始、Fisherman Wildの出現、倍率の上昇は、特定の配当やセッション全体の利益を保証しません。倍率は回収した値の計算方法を変えるものであり、次の回転でどのMoney Symbolsが出るかを予測するものではありません。

公式製品ページは中心となる機能を説明していますが、具体的なRTP、ボラティリティ区分、ベット範囲は掲載していません。そのため、第三者の一覧からこれらの数値を転記していません。

## プレイ前に確認したいこと

実際に起動したバージョンのヘルプと配当表を開き、次の項目を確認してください。

- Scatterが3、4、5個の場合に、それぞれ何回のフリースピンが付与されるか
- ボーナス中にどのシンボルがMoney Symbolsとして扱われるか
- Fisherman Wildが表示中の値をどのように回収するか
- 4個目に集めたWildが追加スピンを付与し、倍率を進める条件
- そのバージョンと通貨に適用されるRTPとベット上限

ゲームの正式名称も確認してください。**Bigger Bass Bonanza**は**Big Bass Bonanza 1000**や**Big Bass Football Bonanza**とは別のタイトルです。同じシリーズでも、別作品には異なるルールや数値が使われることがあります。
