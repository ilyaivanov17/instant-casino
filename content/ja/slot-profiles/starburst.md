Starburstは、NetEntが提供する宇宙をテーマにしたスロットです。ゲームの中心となるのは、配当ラインを左右両方向から判定するルールと、星形のWildがリール全体に拡張してリスピンを発生させる機能です。多くの異なるボーナス機能を組み合わせるのではなく、この特徴的な仕組みを軸に構成されています。

## Starburstの基本情報

| 項目 | 提供元が公表している情報 |
|---|---|
| 開発元／提供元 | NetEnt |
| リリース日 | 2012年1月23日 |
| リール構成 | 5リール × 3段 |
| 配当ライン | 10本。左右両方向から判定 |
| NetEntの現行ページに記載されたRTP | 96.08% |
| NetEntが公表するヒット頻度 | 23.00% |
| NetEntが公表する最大配当 | ベット額の800倍 |
| 提供元ページに記載されたベット範囲 | €0.10～€100.00 |
| ボラティリティ | NetEntの現行ページには記載なし |

これらは公開されている製品情報であり、すべてのカジノ版が同じ設定で動作するという保証ではありません。ベット上限やRTPは、ゲームの設定や運営者によって異なる場合があります。実際に起動したバージョンの情報画面で確認してください。

## 配当ラインの仕組み

Starburstには10本の配当ラインがあります。Evolution Gamesのゲーム説明によると、これらのラインは左から右、右から左の両方向で配当判定されます。これは「Win Both Ways」と呼ばれるルールで、必ずしも左端のリールから一致が始まる必要はありません。

ただし、ベットすれば自動的に配当が発生するという意味ではありません。有効なライン上で、シンボルが所定の組み合わせを作る必要があります。どの並びが配当対象となり、金額がどう計算されるかは、ゲーム内の配当表で確認してください。

## 主な機能：拡張Wildとリスピン

特徴的なシンボルは、星形のStarburst Wildです。NetEntの説明では、このシンボルが出現するとリール全体を覆うように拡張します。拡張した状態では、通常の配当対象シンボルの代わりとして機能します。また、拡張Wildによってリスピンが発生し、残りのリールでも一致するシンボルが出る機会がもう一度与えられます。

仕組みは次の3段階に分けて考えると分かりやすくなります。

1. **Wildを見分ける：** 星形のWildと、通常の宝石・BAR・7のシンボルを区別します。
2. **拡張したリールを確認する：** Wildは対象リール全体を覆うため、配当ライン上の複数の位置をカバーすることがあります。
3. **リスピンの結果を見る：** 追加の回転はこの機能の一部です。配当の成立や収支がプラスになることを保証するものではありません。

機能そのものは見分けやすい一方、結果はほかのリールに停止するシンボルにも左右されます。演出やリスピンの発生から、次の回転の結果を予測することはできません。

## RTP・ヒット頻度・最大配当の見方

NetEntの現行Starburst製品ページには、RTP 96.08%、ヒット頻度23.00%、最大配当はベット額の800倍と記載されています。RTPは非常に多くのゲームラウンドを対象とした理論値であり、個別のセッションで戻る金額を予測するものではありません。ヒット頻度も、1回のプレイで純利益を得る確率を意味しません。

公表されているRTPには小さな差があります。NetEntの現行ページは96.08%ですが、Evolution Gamesのページでは96.09%と記載されています。具体的なゲームバージョンを確認せず、どちらかをすべての環境に共通する値として扱うべきではありません。カジノで実際に起動したバージョンについては、そのゲーム内ヘルプまたは情報画面を確認してください。

NetEntの現行製品ページにはボラティリティの区分が記載されていません。そのため、このプロフィールでは独自に「低・中・高」と分類していません。

## プレイ前に確認したいこと

利用するバージョンのルールを開き、次の点を確認してください。

- タイトルが類似名の別作品ではなく、**Starburst**であること
- そのバージョンに表示されるRTP
- 利用通貨での最低・最高ベット額
- 10本の配当ラインと両方向の判定方法

同じゲーム名でも、運営者や提供地域によって設定が異なる場合があります。製品紹介ページの数値が、現在読み込まれているゲームの設定と完全に一致するとは限りません。
