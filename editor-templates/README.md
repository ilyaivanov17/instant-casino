# Editorial templates

Copy the required Markdown file into the relevant `content/` section, give it a URL-friendly filename, and replace the example values. For translations, create a file with the same name and the language suffix, such as `.en.md`, `.fr.md`, or `.es.md`.

- `page.md` — standard content page.
- `article.md` — editorial article.
- `slot.md` — game page.
- `payment.md` — payment method page.
- `faq.md` — FAQ entry.

Review all claims and verify sources before publishing.
